installer-generated metadata absent from public Git. Amendment 002 and the v1
review preserve that finding. No live generator calls preceded either freeze.

to v1. Only source binding and preparation/qualification envelopes changed.

configuration, and planning power. `prepared/manifest.json` binds the four input
files. Reference labels are authored and no evaluation observations are present.

The artifact publication commit follows the source commit in the freeze.
Only the immutable bundle is published here; runtime claims and credentials
remain separate. This bundle is not an execution release.
