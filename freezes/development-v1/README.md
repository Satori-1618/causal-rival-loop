# Public development freeze v1

This bundle was prepared before any live generator calls. Execution remains
pending review, a human release, and an API credential.

`freeze.json` binds the frozen source commit, prepared manifest, qualification,
configuration, and power calculation. `prepared/manifest.json` binds the four
input files. The prepared population includes authored reference labels; it
contains no measured evaluation outcomes. The generator receives only the
protocol-permitted payload and has no external tools.

The publication commit follows the source commit recorded in the freeze.
The five prepared files and qualification are explicitly tracked here because
the ordinary artifacts and runtime freeze directories are otherwise ignored.
Review and run records will be separate artifacts; this is not a release.
